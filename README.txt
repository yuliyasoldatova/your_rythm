РИТМ — публикация на GitHub Pages

1. GitHub → New repository → например ritm-app (Public).
2. Откройте репозиторий → Add file → Upload files.
3. Загрузите ВСЕ файлы из этого архива в КОРЕНЬ репозитория (не ZIP целиком).
   Должны лежать рядом: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png.
4. Commit changes.
5. Settings → Pages → Build and deployment → Source: Deploy from a branch.
6. Branch: main, Folder: /(root), Save.
7. Адрес: https://ВАШ-ЛОГИН.github.io/ritm-app/
8. На iPhone открыть в Safari → Поделиться → На экран Домой.
   На Android Chrome → меню → Установить приложение / Добавить на главный экран.

ВАЖНО:
* GitHub Pages публичен: не выкладывайте в репозиторий дневниковые записи, дампы Firestore, ключи доступа или иные персональные данные.
* Дневник работает локально и сохраняется только в браузере устройства, без синхронизации.
* Не меняйте адрес/домен сайта без резервной копии записей.
* Публичный сайт не является приватным кабинетом Senim Expert.
* Приложение не предназначено для контрацепции или постановки диагноза.
